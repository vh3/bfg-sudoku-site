Support

Need help with BFG Sudoku, found a bug, or have accessibility feedback? Email us — we read every message.

Support email: bfgames.support@gmail.com

What to include

  • Device model and iOS version
  • App version (Settings → General → iPhone Storage → BFG Sudoku, or the About screen when available)
  • What you were doing when the issue happened
  • Screenshots if they help

Source code

The iOS application source repository is private. Please use the support email above rather than GitHub for product help.
