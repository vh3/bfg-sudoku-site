Support

Brauchen Sie Hilfe bei BFG Sudoku, haben Sie einen Fehler gefunden oder Feedback zur Barrierefreiheit? Schreiben Sie uns — wir lesen jede Nachricht.

Support-E-Mail: bfgames.support@gmail.com

Bitte angeben

  • Gerätemodell und iOS-Version
  • App-Version (Einstellungen → Allgemein → iPhone-Speicher → BFG Sudoku)
  • Was Sie gerade getan haben, als das Problem auftrat
  • Screenshots, falls hilfreich

Quellcode

Das iOS-Quellcode-Repository ist privat. Bitte nutzen Sie die Support-E-Mail oben und nicht GitHub für Produkthilfe.
